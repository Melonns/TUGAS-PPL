# Checklist Testing

## Unit Test
- Validasi input logbook
- Simpan draft
- Submit logbook
- Update logbook
- Hapus logbook

## Integration Test
- Login lalu akses logbook
- Create logbook dengan bukti file
- Mentor approve / revisi
- Resubmit setelah revisi

## UAT
- Mahasiswa buat logbook dari awal
- Mahasiswa simpan draft lalu submit
- Mentor cek dan approve
- Mentor minta revisi lalu mahasiswa kirim ulang
