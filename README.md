# Tugas PPL - Logbook Mahasiswa

Folder ini disiapkan sebagai workspace terpisah untuk fitur logbook mahasiswa, termasuk alur draft, submit, dan approval mentor.

## Struktur

- `backend/` - source API atau logic backend yang dicopas dari project lama
- `frontend/` - source UI atau tampilan yang dicopas dari project lama
- `docs/` - proposal, latar belakang, kebutuhan, dan catatan UAT
- `tests/` - unit test, integration test, dan checklist pengujian
- `deployment/` - catatan environment, setup, dan panduan run

## Catatan

- Repo lama tetap dibiarkan utuh.
- Folder ini dipakai untuk menampung salinan fitur yang relevan.
- Fokus utama fitur: logbook mahasiswa + verifikasi mentor.
